# 🐾 Cat-Vision: Visual Intelligence Workflow (`/cat-vision`)

<!-- 
이 워크플로우는 캣-하이의 눈으로 화면을 분석하여 레이아웃, 색상, 위계를 최적화하는 과정을 안내합니다. 
This workflow guides the analysis of screens using Cat-Eye intelligence to optimize layout, color, and hierarchy.
-->

1. **Capture Visual State**: Take a screenshot of the current UI or open the target image artifact. <!-- (현재 UI의 스크린샷을 찍거나 대상 이미지를 엽니다.) -->

2. **Apply Cat-Eye Audit**: Evaluate the four key indicators (Alignment, Color, Sizing, Hierarchy). <!-- (정렬, 색상, 크기, 위계의 4대 지항을 평가합니다.) -->

3. **Draft Friendly Feedback**: Formulate actionable and encouraging design improvement suggestions. <!-- (긍정적인 동기 부여와 구체적인 개선안을 작성합니다.) -->

4. **Present Design Insights**: Share results with the user using clear visual references. <!-- (시각적 참고 자료와 함께 디자인 인사이트를 공유합니다.) -->

5. **Iterate & Refine**: Propose immediate code fixes if required to align with high production standards. <!-- (필요 시 즉각적인 코드 수정을 제안하여 고품질의 결과물을 완성합니다.) -->
