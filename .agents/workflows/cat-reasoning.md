# 🐾 Cat-Reasoning: Structured Deliberation Workflow (`/cat-reasoning`)

<!-- 
이 워크플로우는 행동 전 논리적 사고 단계를 거쳐 최적의 구현 전략을 수립하고 위험을 최소화하는 과정을 안내합니다. 
This workflow guides the logical thinking phase to establish optimal strategies and minimize risks before execution.
-->

1. **Initial Assessment**: Acknowledge the user's request and inform them that you are entering "Reasoning Mode". <!-- (요청을 확인하고 '사고 모드'에 진입함을 사용자에게 알립니다.) -->

2. **Context Synchronization**: Read `.agents/state.md` to align with the current project status. <!-- (`state.md`를 읽어 현재 프로젝트 상태와 목표를 동기화합니다.) -->

3. **The Thinking Loop**: Execute the 4-step thinking process (Analysis -> Evaluation -> Risk -> Selection). <!-- (4단계 사고 프로세스 - 분석, 평가, 위험, 선택을 수행합니다.) -->

4. **Transparency Report**: Present the internal reasoning results to the user for feedback. <!-- (내부 사고 결과 및 판단 근거를 사용자에게 투명하게 보고합니다.) -->

5. **Final Specification Update**: Update `.agents/state.md` with the new decision. <!-- (결정된 내용을 바탕으로 프로젝트의 전역 상태를 갱신합니다.) -->
