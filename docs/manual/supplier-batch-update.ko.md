# 새 배치 업데이트 사용법

2026-09-08 승인된 코발트 블루 화면 기준. 운영 화면의 배치 실행 및 결과 확인 안내.

## 아이허브 전체 상품 업데이트

1. **배치 업데이트 → 새 배치 실행**에서 소싱처를 **아이허브 · IHB**로 선택한다. 옆의 **전체 상품 N개**가 이번 소싱처의 활성 상품 수다.
2. **가격 + 재고**를 선택한다.
3. **목표 마진율 10%**, **소싱처 쿠폰 할인율 20%**, **최소 마진 1,500원**을 입력한다. 쿠폰이 없는 날은 쿠폰 할인율을 **0%**로 바꾼다. 소싱처 쿠폰은 구매할 때 받는 할인이다.
4. 반영할 마켓을 체크하고 **N개 업데이트 시작**을 누른다.

이후 최신 가격·재고 수집 → SB 저장 → 연결된 선택 마켓 반영이 진행된다. 상품을 50개씩 따로 선택할 필요가 없다. 시작 시 대상과 조건을 고정하며, 화면의 표시 개수나 검색 조건을 바꿔도 실행 대상은 달라지지 않는다.

**가격 + 재고 모드는 두 항목을 모두 수집해야 저장한다.** 하나만 수집되면 해당 상품 전체를 실패 처리하고, SB 상품값과 마켓값을 변경하지 않는다. 실패 상품을 재시도하면 가격과 재고를 함께 다시 수집한다. 다른 상품의 배치는 계속 진행된다.

접수가 끝나면 실행 폼을 접고 진행 현황을 보여준다. 상단의 **새 배치 실행**을 누르면 입력했던 조건으로 폼을 다시 펼칠 수 있다.

소싱처별 최근 실행 조건을 자동으로 불러온다. 시작 전 입력값을 확인한다. **기본값**은 소싱처 기본 조건을 불러오는 버튼이며, 기존 상품을 변경하거나 배치를 실행하는 버튼이 아니다.

## 11번가 가격 반영

지원 조건을 충족한 상품은 계산된 **설정 판매가로 자동 반영**한다. 인상과 인하 모두 대상이며, 상품 기본 판매가를 변경한다. 옵션별 가격이나 즉시할인 설정을 함께 변경하지 않는다.

**가격을 인상하면 11번가에서 적용하던 쿠폰·수수료 혜택이 종료될 수 있다.** 이 가능성을 인정하고 설정 판매가를 반영하는 것이 사용자가 승인한 자동 처리 기준이다. 여기서 말하는 11번가 혜택은 화면에 입력하는 **소싱처 구매 쿠폰 할인율과 별개**다.

판매 중·품절·전시중지 상태에서 지원되는 가격 변경을 처리하며, 승인 대기·판매금지·종료 등 지원하지 않는 상태는 사유와 함께 보류한다. 가격 변경 응답만으로 성공 처리하지 않고, 별도 재조회에서 목표 판매가와 일치해야 **반영 확인**으로 표시한다.

## 품절·구매 가능 여부만 갱신

**재고만**을 선택하면 가격 조건 입력이 비활성화된다. 최신 소싱 재고 상태를 확인해 지원되는 마켓에 반영한다. 상품의 판매용 설정 수량은 유지하며, 임시 품절 상태와 판매금지 처분을 구분한다.

마켓이 판매 재개나 품절 전환을 지원하지 않거나 필요한 확인이 없으면 **보류**와 사유를 표시한다. 수집 실패를 품절로 간주하지 않는다.

11번가는 단일 재고 항목의 수량 조정과 0개 처리, 허용된 상태에서의 판매 재개를 지원한다. 양수 수량은 설정한 수량과 판매 가능 상태를, 0개는 실제 재고 0개와 구매 불가 상태를 함께 재조회해 확인한다. 수량만 일치하고 판매 상태를 확인하지 못한 경우에는 성공으로 표시하지 않는다.

전시중지와 품절은 서로 다른 상태로 표시한다. **영구 판매금지·강제종료 상품은 재개하지 않는다.** 지원하지 않거나 불명확한 상태는 보류 사유를 확인한다.

## 처리 현황 읽기

**배치 실행 기록**에서 실행 한 건의 행을 펼친다.

| 표시 | 의미 |
|---|---|
| 처리 N / 전체 N | 성공뿐 아니라 실패·보류로 처리가 끝난 상품도 포함 |
| 성공 / 실패 / 보류 / 대기·처리 | 상품 단위 결과 요약 |
| 수집 | 소싱처 최신 정보를 가져온 결과 |
| SB 저장 | 시스템 상품에 저장한 결과 |
| 쿠팡·11번가·스마트스토어·카페24 | 마켓별 가격·수량 반영 결과 |
| 문제 · 조치 | 실패·보류 원인과 재시도 버튼 |

**처리 완료는 전체 성공을 의미하지 않는다.** 실패·보류 수를 함께 확인한다. SB 저장 완료도 마켓 반영 완료와 다르다. 가격·수량은 전송 후 마켓을 재조회해 목표값과 필요한 판매 상태가 확인되어야 성공으로 표시한다. 카페24 반영 확인은 G마켓·옥션까지 확인했다는 뜻이 아니다.

상품 검색과 결과 필터는 펼친 배치 내에서만 작동한다. 상품명 또는 SB코드로 찾고 **실패만**, **보류만**을 선택하면 확인할 상품을 좁힐 수 있다. 페이지를 넘겨 전체 상품의 기록을 볼 수 있다.

상품이나 상태를 클릭하면 **상품 처리 상세**가 열린다. 단계별 목표값·확인값, 마지막 처리 시각, 시도 횟수, 오류 이력과 가격 계산 근거를 확인한다. 마켓별 수수료에 따라 목표 판매가는 달라질 수 있다.

한 상품에 문제가 여러 개면 첫 사유와 **외 N개 문제**가 보인다. 이를 누르면 나머지 사유와 각 단계의 재시도 버튼을 확인할 수 있다.

최소 마진은 판매가에서 쿠폰을 적용한 총매입가와 국내 배송비를 뺀 금액을 기준으로 하는 기존 계산 규칙을 따른다.

## 실패한 부분만 다시 처리

- 상품 행의 **해당 단계 재시도**: 그 상품의 해당 수집·저장·마켓 가격/수량 단계만 재접수한다.
- **실패 단계 일괄 재시도**: 이 배치 전체의 재시도 가능한 실패 단계를 모아 처리한다. 창에 단계별 건수를 표시한다. 현재 페이지·검색·필터 범위와는 무관하다.
- 이미 성공한 단계는 재사용한다. 수집 실패를 재시도해 성공하면 아직 실행하지 못했던 저장과 마켓 단계가 이어진다.
- 판매금지·미지원·입력 수정이 필요한 단계는 원인을 먼저 해결해야 하며 자동 재시도 대상에서 제외된다.

네트워크가 끊겨 접수 여부를 알 수 없으면 **같은 시작 요청 다시 확인** 또는 **같은 재시도 요청 다시 확인**을 누른다. 같은 요청 번호로 기존 접수를 확인한다.

## 일시정지와 재개

**일시정지**를 누르면 새 작업 시작을 멈추고 이미 실행 중인 요청을 마무리한다. 이때는 **일시정지 중**으로 표시되며, 마무리 후 **일시정지됨**으로 바뀐다. **재개**하면 남은 작업부터 이어간다.

일시정지 중 실패 재시도를 접수해도 배치는 자동으로 재개되지 않는다. 브라우저를 닫는 것은 일시정지가 아니며 작업 기록은 서버에 보존된다.

오래 멈췄더라도 수집 결과가 유효하면 전송 전 검토를 갱신해 이어간다. 수집 결과 자체가 만료되었거나 상품·연결·계정이 달라졌다면 보류 사유를 확인해야 한다. 만료된 가격을 그대로 적용하지 않는다.

**수집한 지 24시간이 지나 적용 보류**라고 나오면 해당 저장 단계를 재시도한다. 아직 저장하지 않은 그 상품만 다시 수집하며, 이미 성공한 다른 상품과 마켓 작업은 유지한다. 그 사이 상품이나 연결 정보가 달라졌다면 변경 충돌을 먼저 해결해야 한다.

같은 소싱처에 진행 중이거나 일시정지한 배치가 있으면 새 배치를 중복 시작하지 않는다. 기존 실행 기록에서 상태를 확인한다.

## 아이허브 할인 제외 상품

가격 업데이트 시 수집 JSON의 `discountType`과 `discountDisplayType`이 **둘 다 정수 0**이면, 입력한 쿠폰율 대신 **0%**로 SB 가격과 각 마켓 목표 판매가를 계산한다. 예를 들어 쿠폰율 20%로 배치를 실행해도 해당 상품은 할인 없이 구매하는 금액으로 계산한다.

배치 실행 조건에는 입력한 쿠폰율을 유지하고, 상품 처리 상세의 **입력 쿠폰율 → 실제 적용 쿠폰율**과 안내 사유에서 상품별 적용 결과를 확인한다. 재고만 업데이트할 때는 가격 정책을 변경하지 않는다. 다른 값의 조합이나 필드 누락은 이번 제외 규칙의 대상이 아니며 입력 쿠폰율을 유지한다.
