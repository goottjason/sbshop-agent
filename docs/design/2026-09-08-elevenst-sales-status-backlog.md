# 백로그: 11번가 판매 중 상품이 적게 남은 원인 조사

- 상태: 추후 조사. 사용자 요청에 따라 현재 수량 기능 구현과 별도 보관한다.
- 접수: 2026-09-08, 사용자가 11번가 판매 중 상품 목록 캡처를 제공했다.
- 근거: [사용자 제공 원본 캡처](evidence/2026-09-08-elevenst-active-products-user.png).
- 사용자 관측: 캡처의 상품들이 현재 판매 중인 상품의 전부로 보이며, 나머지는 품절 또는 판매중지 상태라고 설명했다. 이 관측을 전체 API 집계 결과로 확정하지 않는다.
- 질문: 처음 등록했던 다수 상품 중 현재 판매 중 상품이 적게 남은 이유는 무엇인가?
- 원인: 미확인. 과거 배치 수량 변경, 실제 소싱 품절, 판매자 수동 조치, 마켓 조치 등을 근거 없이 원인으로 단정하지 않는다.

향후 조사에서는 현재 계정 전체 상품을 판매 중·품절·판매중지·삭제·영구금지로 구분 집계하고 SB 연결과 대조한다. 상태 변경 시점과 과거 수량/중지/재개 API·배치 이력, 당시 소싱 재고 증거를 교차 확인한다. API나 화면에 사유·시각이 없는 경우 미확인으로 남긴다. 조사만으로 일괄 판매 재개하거나 수량을 변경하지 않는다.

## 표본 선정 중 확인한 단서

같은 날 위 14개 코드만 SB DB에서 읽기 전용으로 대조했다. 14개 모두 11번가 상품번호·LINKED 등록 이력이 있었지만, SB 상품 행은 **13개가 `deleted_at` 비어 있지 않음**, `220114OC012`(상품 ID 1229)만 활성 상태였다. 첫 코드 `231113IHB048`을 활성 상품으로 찾지 못한 뒤 정확한 코드 목록만 확인한 결과다.

이것이 판매 중 상품 수 감소의 원인이라는 뜻은 아니다. 13개의 삭제 시각·행위자·관련 배치·외부 상태는 아직 조사하지 않았다. 사용자 요청에 따라 현재 상품을 복원하거나 연결·판매 상태를 변경하지 않았다. 향후 **SB에서 삭제된 상품이 외부 마켓에서는 계속 판매되는지**, 삭제 처리 시 외부 연결 관리가 어떻게 동작했는지도 함께 확인해야 한다.
