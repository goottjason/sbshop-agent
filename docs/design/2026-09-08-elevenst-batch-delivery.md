# 11번가 가격·품절 지원과 배치 화면 배포 전 검증

사용자는 11번가 수정·재조회 경로 구현과 검증 후 배포를 요청했다. 가격 인상으로 11번가 측 협의 쿠폰·수수료 혜택이 종료될 수 있음을 인정하고 설정 판매가로 자동 반영하도록 승인했다. 구매 원가의 소싱처 쿠폰은 마켓의 즉시할인과 별개다.

## 이번 지원

- 11번가 가격 전용 변경 GET과 별도 상세 GET을 검토형 가격 큐에 연결했다. 상품번호·SB코드·계정·현재 상태를 확인하고 전송 직전 DB의 작업 소유권·일시정지·수정 여부·429 제한을 다시 확인한다.
- 실제 수량 0과 품절 상태, 양수 수량과 판매중 상태를 각각 재조회해야 수량 작업이 완료된다. 일시 전시중지와 영구 판매금지·강제종료를 구분하며 후자는 재개하지 않는다.
- 접수 응답만으로 완료하지 않는다. 결과가 불명확하면 먼저 재조회하며, 명시적 거절을 자동 반복 전송하지 않는다. 가격 GET과 수량 PUT은 전송기 내부 자동 재전송·리다이렉트를 차단한다.
- 승인된 코발트 블루 배치 화면과 소싱처 전체 실행, 실행별 상품·단계 상태표, 실패 부분 재시도를 함께 배포한다. 가격·재고를 함께 요청했는데 하나라도 수집되지 않으면 상품 전체 실패로 끝내며 SB 상품값 저장과 마켓 반영을 진행하지 않는다.

## 실제 검증

단일 검증 상품 `220114OC012`의 새 어댑터를 운영 네트워크에서 독립 Java 프로세스로 실행했다. 기존 앱을 먼저 교체하거나 전체 소싱처 배치를 실행하지 않았다. 공유 마켓 호출 잠금, 현재 계정·상품 연결 및 SB 행 해시 검사를 적용했다.

| 검증 | 별도 재조회 결과 |
|---|---|
| 가격 인하 | 217,800원 → 217,700원 |
| 가격 원복 | 217,700원 → 217,800원 |
| 품절 | 수량 300·판매중 103·재고 01 → 수량 0·품절 104·재고 02 |
| 판매 재개 | 수량 0 → 300·판매중 103·재고 01 |
| SB 상품 정보 | 전체 행 해시 동일 |

실제 가격 접수 응답의 `productNo`가 비어 있어 문서와 달랐다. 검증 기준을 완화하지 않고 불명 응답 뒤 정확한 상품의 별도 GET으로 가격을 확인했다. 큐의 `INVALID_RESPONSE → VERIFY → CONFIRMED_PRICE` 복구와 추가 변경 요청 없음도 회귀로 검증했다. 첫 임시 검증 도구가 접수 예외를 즉시 종료로 처리한 문제는 도구에서 수정했으며, 가격 원복은 별도 조회로 확인했다. [최종 실상품 증거](evidence/2026-09-08-elevenst-price-stock-adapter-live.json).

전체 백엔드 3,187건이 통과했다. 실제 응답 예외를 보강한 최종 가격 큐 18건, 가격 어댑터 31건 및 실제 PostgreSQL 배치 22건도 통과했다. 수량 PostgreSQL 47건·어댑터 39건·DDL 1건, Chrome 배치 18개 흐름과 상태 표시 7개 흐름을 별도로 확인했다. 프런트 타입 검사·빌드가 통과했다. [검증 집계](evidence/2026-09-08-elevenst-batch-predeploy-verification.json).

## 배포 선행 조건

최종 배포 후에는 API·화면 응답과 실행 버전을 확인한다. 이 문서의 실상품 검증은 단일 상품 범위이며 전체 2,000여 상품의 운영 배치를 완료했다는 뜻은 아니다. 사용 방법은 [배치 업데이트 매뉴얼](../manual/supplier-batch-update.ko.md)에 있다.
