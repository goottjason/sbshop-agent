# 상품 관리 후속 납품 체크리스트

이전의 약 60%는 완료 조건별 점수표가 없는 범위 추정치였다. 이번부터 아래 기능 단위와 가중치를 고정하여 배포된 기능의 증가분을 표시한다. 점수는 업무 범위에 대한 관리용 추정이며 코드 줄 수·테스트 개수·소요 시간의 비율이 아니다. 같은 기능의 오류 수정·재검증·재배포는 중복 가산하지 않는다.

## 고정한 산정 기준

| 영역 | 전체 비중 | 이번 작업 전 기준점 | 이번 납품의 증가 가능 점수 | 미완료 핵심 |
|---|---:|---:|---:|---|
| 화면·검색 | 20 | 16 | +2 | 전체 마켓 실패 조건 등 남은 검색 조합 |
| DB 편집·정책 | 15 | 8 | +4 | 그 외 연결 상품의 수정 필드 개방 |
| 소싱 갱신 | 15 | 6 | 0 | 타 소싱처·검토형 가격/재고 수집 통합 |
| 외부 동기화 | 25 | 12 | +2 | 다른 필드·마켓, G마켓/옥션 최종 값 확인·자동 재전송 |
| 연결 점검 | 10 | 8 | 0 | 다른 마켓 정기 점검 확대 |
| 검토 등록 | 10 | 5 | 0 | 스마트스토어 외 마켓의 검토 등록 |
| 운영 배포 기반 | 5 | 5 | 0 | 필드별 실제 운영 검증은 해당 기능에서 평가 |
| 합계 | 100 | 60 | +8 | 모두 납품하면 약 68% |

기준점 60은 이전 추정치를 위 영역에 배분한 값이다. 정밀한 실적 집계로 소급 해석하지 않는다. 이번 증가분은 아래 완료 조건을 구현·통합·배포한 뒤에만 확정한다. 실제 외부마켓 변경을 하지 않은 항목을 운영 쓰기 검증 완료로 표기하지 않는다.

## 이번 기능 단위와 완료 조건

| ID | 점수 | 완료 조건 | 현재 상태 |
|---|---:|---|---|
| F01 | 1 | 이미지/HTML 수집·DB 적용 네 시각, 30/60/90/180/365일 또는 적용 기록 없음 검색, 현재 소싱처 증거만 사용 | 로컬 검증 완료 · 배포 대기 |
| F02 | 1 | 조치 필요 우선 → 콘텐츠 적용 오래된 순 기본 정렬, 일반 필드 정렬, 전체 DB 기준 count·페이징 일관성 | 로컬 검증 완료 · 배포 대기 |
| E01 | 3 | 비숫자 17필드 일괄 선택·검토·저장, 명시 비우기, 잠금/파생값/부분 실패/동일 검토 재시도, 큰 HTML 조기 제한 | 로컬 검증 완료 · 통합/배포 대기 |
| S01 | 2 | 쿠팡·카페24 본상품 수량 검토/영속 작업/화면, 정확한 계정·SB·옵션, 별도 재조회 일치, 429/불명/명시 거절 처리 | 로컬 1차 검증 완료 · 통합/배포 대기 |
| E02 | 1 | 쿠팡만 연결된 상품의 판매용 수량 편집, 저장→자동 수량 접수→필드별 결과; 가격과 동시 저장 시 대상 분리 | 구현·통합 검사 중 |

수량은 원본 DB 재고 수치를 그대로 전송하지 않는다. 명시 IN_STOCK은 판매용 설정 수량, 명시 OUT_OF_STOCK은 0이다. 출처 소실·수집 실패·상태 불명은 보류한다. 승인·판매 상태와 마켓플러스 전달 범위가 확인되지 않은 상품도 보류하며, 판매 재개 API는 이 수량 작업에 포함하지 않는다.

## 검증·배포 증거

현재 각 에이전트의 국소 검증과 독립 검토를 수행했다. 최종 통합 검사·DDL 검증·운영 API/Chrome·배포 버전은 이 문서에 후속 기록한다. 로컬 fixture는 실제 운영 API 검사와 구분한다.
