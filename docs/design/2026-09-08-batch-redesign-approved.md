# 배치 업데이트 UI/UX 승인 기준

사용자가 기본 화면은 청록 대신 코발트 블루로 변경하여 승인했고, 이어 오류 상세·실패 단계 재시도·일시정지/재개 상세안에 “응 괜찮아”로 승인했다. 상품 관리는 보류하고 배치 업데이트만 구현한다.

승인 시안: [기본 화면](evidence/batch-redesign-approved/main-cobalt.png), [상세 동작](evidence/batch-redesign-approved/details-cobalt.png). 이미지 수치·상품은 예시이며 운영 관측값이 아니다.

- 코발트 #2454D8, 성공 초록/주의 주황/실패 빨강, 밝은 배경과 읽기 쉬운 계층.
- 소싱처 전체 대상·가격+재고/가격만/재고만·마진/소싱 구매 쿠폰/최소마진·연결 마켓 선택 후 한 번 실행. 상품별 추가 승인·50개 수작업 없음.
- 실행 당시 대상/조건을 고정. 수집→DB 저장→선택한 연결 마켓별 반영. 미등록 마켓 제외.
- 실행 1건=부모1행, 펼치면 서버 페이지로 전체 상품 조회. 수집/DB/각마켓 상태·가격·사유. 표시 페이지와 실행 범위는 분리.
- 실패 단계만 개별/일괄 재시도, 성공 단계 재사용. 응답 불명은 읽기 우선, 영구금지/입력수정 필요 무한재시도 금지.
- pause 요청시 신규 단계 시작을 멈추고 진행중 외부 요청을 마무리, resume은 남은 단계부터. 브라우저 종료와 무관한 영속 기록.
- 처리율100%는 전부성공 아님. 완료/확인필요/진행대기 분리. DB성공≠마켓성공, Cafe24성공≠G/A성공.
- 임시품절/재입고와 영구판매금지 구별. 확인되지 않은 마켓 API는 추측 구현하지 않고 해당 단계에 보류 사유 표시.
- 승인 범위: 화면 및 상세 동작 구현. 이번 작업에서 실제 소싱처 전체 운영 배치 실행은 하지 않는다.
