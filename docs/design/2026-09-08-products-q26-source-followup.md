# 단일 계정의 상품 부재 처리와 소싱 적용 보완

2026-09-08 사용자는 쿠팡·11번가·카페24 각각 현재의 한 판매자 계정만 사용하며, 해당 계정에서 존재하지 않는 상품번호는 활성 연결에서 제외하라고 확인했다. 과거 번호와 부재 판정 근거는 연결 이력으로 보존한다. 마켓플러스 재고관리 설정과 SB 판매용 수량을 함께 비교·선택 적용하는 방향도 승인했다.

## 변경

- 세 마켓의 현재 계정 참조를 각 마켓의 기존 검사 게이트에 최초 한 번 기록하고 사용자 확인 시각·근거를 보존한다. 이후 계정이 바뀌어도 자동으로 다시 고정하지 않는다. 스마트스토어의 기존 확인을 다른 마켓에 재사용하지 않는다.
- 상품 부재 관측은 `PRODUCT_ABSENT/`로 명시 삭제·영구 판매금지와 구분하고, 해당 마켓에 고정한 계정이 일치할 때만 연결 해제를 허용한다. 일반 HTTP 오류·빈 응답·권한 오류·429를 상품 삭제로 확대하지 않는다.
- 소싱 콘텐츠는 화면 조회·검토·저장 직전에 현재 소싱처와 상품 URL을 수집 당시 값과 대조한다. 완료된 검토의 재요청은 기존 이력과 적용 시각을 보존한다.
- 원본 이미지 URL은 내부 추적값으로 저장하고 게시 이미지 변경만 마켓 반영 대상으로 기록한다. 연결 마켓의 실제 게시 이미지 수정 제한은 유지한다. 외부마켓 전송 화면에서도 원본 URL 선택을 제거했다.

소싱 회귀 상세는 [적용 전 점검](2026-09-08-source-apply-preflight.md), 마켓플러스의 실제 저장·옵션 처리 조사와 아직 부족한 계약은 [선택 전송 후속 조사](2026-09-08-marketplus-selected-execution-followup.md)에 기록했다. 마켓플러스의 옵션 토글은 옵션 초기화까지 발생시킬 수 있으므로 사용자 승인만으로 수량 전용 쓰기 경로라고 해석하지 않는다.

## 검증 범위

핵심 백엔드 전체 1,680건 통과 후, 상품 부재 계정 가드를 확장한 최종 연결 검사 34건을 추가 실행해 통과했다. 이는 독립된 테스트 1,714개라는 뜻이 아니다. 소싱·공통 편집 82건은 전체 검사에 포함된다. 프론트 타입 검사와 빌드, 원본 URL 선택/과거 작업 재검토를 포함한 브라우저 fixture 12항목도 통과했다.

외부마켓에 상품 생성·가격·재고·HTML을 쓰는 최종 검증과, 상품 부재를 읽어 SB 내부 연결만 해제하는 검증을 구별한다. 배포 및 실제 연결 해제 결과는 완료 후 이 문서에 추가한다.
