# 상품 관리 실사용 진행상황 — 2026-09-08

기존 고정 기능 단위 추정은 약 89%였으나, 이번 사용자 업무 대조에서 소싱처 전체 배치 동선 공백을 확인했다. 종전 수치가 모든 기존 업무의 89% 복구나 전체 배치 사용 가능을 의미하지 않는다. 새 검증 한 건만으로 100% 또는 더 높은 전체 완료율을 선언하지 않는다.

| 범위 | 완료·검증한 내용 | 남은 내용 |
|---|---|---|
| 상품 화면 | 검색·다중 SB코드·필터/정렬·밀도·단건/일괄 검토 편집 배포 | 사용자 업무 흐름 개선, 전체 결과 대상 작업 |
| 소싱 갱신 | IHB/VTB/FTN/COK/OCD 수집·비교, 선택 저장 구현 | 실제 선택 콘텐츠 DB 적용의 운영 왕복 검증, 전체 소싱처 배치 |
| 가격 조건 변경 | 마진·쿠폰·최소마진 값 지정·검토·저장 구현 | 새 정책과 최신 수집을 하나의 전체 배치로 묶는 동선 |
| 마켓 연결 | 단일 계정 부재 판단, 표본 3건 실제 해제·이력 보존 | 11번가 판매중 상품 감소 원인 별도 백로그 |
| 11번가 수량 | 사용자 승인 220114OC012 실제 전송 1회, 997→300개 독립 재조회 완료 | 0개·품절 복구·판매 재개 계약 |
| 외부 마켓 반영·등록 | 검토/영속 작업/오류·별도 조회 구조, 11번가 주소 선택·등록 입력 준비 | G마켓/옥션 최종 반영 자동화, 11번가 실제 등록, 카페24 생성 이미지 검증, 나머지 실제 선택 쓰기 |
| 운영·안내 | 실행 버전16ec51f6, API/프론트/작업자 배포·스키마 확인; 사용자 매뉴얼 작성 | 전체 배치 동선 보완 뒤 매뉴얼 갱신 |

이번에는 운영 상품 변경 없이 조회 및 숫자 읽기 전용 계산만 수행했다. IHB 활성 2,114개, 표본 상품의 마진10/쿠폰0/최소마진1500 숫자 계산 통과와 상품 행 불변을 확인했다. 저장 제한 검토/전체 상품 저장/소싱 수집/배치는 실행하지 않았다.

[사용자 매뉴얼](../manual/products-and-batch-user-guide.ko.md), [남은 작업](2026-09-08-products-delivery-remaining.md), [11번가 실제 수량 검증](2026-09-08-elevenst-approved-stock-verification.md).

전체 배치 기능 보완의 완료 조건은 대상 누락 없는 고정 목록, 실행별 정책 검토, 429를 고려한 분할 실행, 재개·실패만 재시도, 작업 전체 진행률과 상품별 DB/마켓 결과 표시다. 정책만 먼저 저장해 과거 원가로 반영된 뒤 최신 수집값을 다시 반영하는 두 단계 작업을 단일 배치와 같다고 설명하지 않는다.
