# 수집 실패 사유 간소화

- 배포 커밋 `58d064f0`, Actions `34302691938` 성공.
- 기본 화면에는 진단 사유 한 줄만 표시한다. 반복 안내·수집/계산 주의 문구 제거, 시각·가격·재고 근거는 접힌 확인 기록으로 이동. 수집 단계에 동일 문구 중복 표시하지 않음.
- iHerb 카탈로그의 상품 id/url 검증 후 boolean `isDiscontinued=true`를 생산 중단으로 판정. 두 가격 Amount가 명시적인 숫자 0이고 유효한 양수 가격이 없으면 별도의 0원 비정상으로 실패 처리한다. 누락값을 0으로 변환하지 않는다. 단종이 0원보다 우선한다.
- 200901WA005(62771), 200906WA005(72374)의 실제 JSON 모두 isDiscontinued=true, listPriceAmount=0, discountPriceAmount=0, isAvailableToPurchase=false 확인.
- 배포 후 두 상품에 한해 소싱 관측 컬렉션 `797a1c9b-6b4c-4d4e-9700-9bb3a5f0b2c9` 실행. 두 건 모두 SOURCE_DISCONTINUED, appliedAt=null. DB 상품 가격·재고 저장 검토/커밋 및 마켓 변경 호출 없음.
- 과거 배치 스냅샷은 보존한다. 같은 소싱 URL의 더 최근 명시적 단종/0원 관측이 있을 때 최근 확인 결과를 별도로 표시한다. 다른 URL의 관측은 사용하지 않는다.
- 진단 테스트 7개, 배치 통합 테스트 30개, 소싱 회귀 테스트 18개 및 기존 브라우저 검증 19개 통과. 프론트 빌드 통과.
