# 2026-07-18 10:16 결과서 — 이메일 수집 중앙 계정(Central) 방식 전환

## 개요
계정 23개마다 앱 비밀번호(2단계 인증) 생성하는 부담을 없애기 위해, 이메일 수집을 **중앙 계정 방식**으로 전환했다. 소싱 Gmail들은 각자 **자동전달(push)**로 중앙 계정 `shouldbe.shopping@gmail.com`에 메일을 모으고, 시스템은 중앙 계정 하나만 IMAP으로 읽는다. 관련 [[iherb-email-tracking-pipeline]] · [[email-accounts-expansion]].

## 결정 근거
- 자동전달은 제목·본문을 원본대로 밀어주고 "Fwd:" 미첨부 → 파서(`OrderEmailParser`, 제목/본문 매칭·발신자 미검증)와 100% 호환(코드 확인).
- 지난번 실패했던 "실시간 아님"은 POP '다른 계정 메일 확인'(최대 1h 지연) 방식 탓 → 자동전달로 교체.
- 앱 비밀번호는 중앙 1개만 필요, 나머지는 전달 설정만(2FA 불필요).
