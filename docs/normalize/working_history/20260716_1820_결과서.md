- 설계 원칙: **지점별 맞춤**(case-by-case). tx 경계는 "오케스트레이션 non-tx + 단위별 @Transactional 빈"(Customs 패턴 재사용), 멱등성은 DB 유니크 제약, 락은 실행 JVM 특성 따라 **단일JVM→in-JVM 가드 / 교차JVM→DB 원자클레임**(advisory lock은 이미 있던 토큰갱신만).

- 게이트: 각 웨이브 리더 단독 `./gradlew test` 전건 SUCCESSFUL(각 ~2m18s). 병렬 fixer 격리로 mid-edit 경합 회피.

## ⚠️ 배포 유의 (F-PSRC-13)
배포 시 `sb_market_registration`에 `(product_id, market_type)` 유니크 제약이 ddl-auto=update로 추가된다. **기존 중복행 있으면 제약 생성 실패로 부팅 영향.** 배포 전 확인:
```sql
SELECT product_id, market_type, count(*) FROM sb_market_registration
GROUP BY product_id, market_type HAVING count(*) > 1;
```
0행이면 안전. 중복 있으면 dedup 선행.
