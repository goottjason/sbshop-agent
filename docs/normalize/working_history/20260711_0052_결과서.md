→ 기능 자체는 동작. **문제는 프론트 피드백/갱신.**

## 근본원인

재고 동기화는 마켓 동기화(완료 시 SSE `SYNC_COMPLETED`로 갱신)와 달리 **완료 신호가 없는 백그라운드 크롤(수 초~수 분)**. 그런데 `handleSyncProductStock`은:
- 성공 토스트가 **없음** (에러 토스트만 존재)
- 고정 **3초 후 refetch**뿐 → 크롤 미완 상태로 refetch돼 재고 값 무변화

결과: 명시적 피드백 없이 3초 오버레이만 잠깐 뜨고 데이터가 안 바뀌어 → 사용자에겐 "눌러도 반응 없음"으로 체감.
