## 5. D-304 보류 1건 종결 (중대 — 사용자 승인 후 커밋)

**사용자 확정 규칙**: 카페24 품절 상품은 `use_inventory=F`로 둔다 / 재실행 시 여전히 품절이면 가격·수량을 아무것도 보내지 않는다 / 판매가능(수량>0)으로 바뀌면 `use_inventory=T`를 먼저 켜고 가격·수량을 조정한다.

두 경로에 같은 규칙을 적용하되 **종결 방식은 호출자에 맞춰 다르게** 했다.

| | reviewed `writeStockQuantity` | 레거시 `syncVerifiedPriceStock` |
|---|---|---|
| ① 품절 + `use_inventory=F` | PUT 0회 + `UnsupportedOperationException` (`beforeWrite` 미실행) | 가격·수량 PUT 0회. 본상품이 아직 `selling=T`면 `{"selling":"F"}` 1회만 |
| ② 재입고 + `use_inventory=F` | `beforeWrite` → `use_inventory:T` PUT → `quantity` PUT | `use_inventory:T` PUT → `quantity`·가격 PUT |

비대칭 근거: `MarketStockSyncService`는 `UnsupportedOperationException`을 **BLOCKED 종결**로 받아 재시도 루프를 끊지만, `ProductMarketSyncService`는 **모든 예외**를 `recordSyncError`로 적재해 품절 상품마다 배치마다 실패가 쌓인다(정상 동작인데 실패로 기록됨).
