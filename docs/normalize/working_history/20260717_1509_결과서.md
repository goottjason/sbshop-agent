- G마켓/옥션 주문은 `Cafe24OrderSyncService`가 Cafe24 Admin API(`/admin/orders?embed=items,receivers,buyer`)로 수집.
- 통관번호 추출 `extractPccc`가 **정확한 Cafe24 필드명을 모른 채 추측 키**(`personal_customs_clearance_code`·`clearance_code` 등)만 시도 → 응답에 값이 있어도 항상 `null` 저장. 코드 주석도 "필드명 문서 미확정" 명시.
- **라이브 ground truth 확보** (사용자 서버 접근 승인): 강연희 주문 `id=185`(GMARKET, cafe24_order_id `20260715-0000010`)의 `customs_clearance_no`가 NULL임을 프로덕션 DB로 재현. 이어 라이브 Cafe24 API를 해당 주문으로 직접 호출해 실제 필드 확정:
  - `receivers[0].clearance_information = "P180023584849"`
  - `receivers[0].clearance_information_type = "C"` (개인통관고유부호 유형)
- 값은 **이미 현재 embed(`receivers`)에 포함** → embed 변경 불필요. 순수 파싱 수정.

- **배포 반영 필요:** 파싱 수정은 **다음 동기화(배포 후)부터** 적용. 서버 재배포(main push=자동배포=api 재시작) 전까지 프로덕션은 구코드.
