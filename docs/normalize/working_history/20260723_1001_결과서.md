## 미해결·주의

- **D-101 DB 정리 대기:** 사용자 승인 하 운영 DB 일괄 UPDATE로 처리(프론트 정규화 코드는 불채택). 에이전트 prod SSH가 auto-mode로 차단돼 **사용자가 직접 실행**. SQL: `UPDATE sb_order_line_item SET discount_code = '정기' WHERE discount_code = '(정기)';` (범용: `... SET discount_code = regexp_replace(discount_code,'^\((.*)\)$','\1') WHERE discount_code ~ '^\(.*\)$';`)
- **D-099 범위:** 개별 편집은 **판매가**만 실 반영. 원가·재고수량·상품명 등 나머지 필드는 여전히 모킹(백엔드 `PATCH /products/{id}` 미구현). 상품 그리드 인라인 편집은 설계상 읽기전용(배치 일괄 업데이트 전용, 커밋 3e57f25) — 유지.

## 핵심 결정과 이유

- 구분선은 셀별 조건부 border(rowSpan 병합으로 경계 셀 산정 복잡·불연속 위험) 대신 **스페이서 행**으로 구현 — 전체 폭 연속선 보장, 로우스팬 무관, 저위험.
- 전화번호는 "쿠팡·스스센"만 분기하지 않고 **전 마켓 공통 포맷**(이미 하이픈 있어도 숫자 재추출→동일 규칙) — 표시 일관성.
