## 핵심 결정과 이유

- **D-022 등급 표준 판정**: 4서비스 다도메인이나 이벤트 발행 조건만 교정(스키마/스케줄러/계약 무변경) → 중대 아님. `.autonomous` 마커로 자동 게이트.
- **D-028/D-029 라이브 데이터 리스크**: 실 주문을 CANCELED로 마킹하는 경로 → Batch1에서 검증된 쿠팡 `isNonTerminal` 정본을 이식하고 오취소 방지(RETURNED/EXCHANGED terminal 포함)를 회귀로 고정. verifier가 "오취소·오생성 없음"을 엄격 심사 후 PASS.
- **D-033 무변경 결정**: 백엔드 `OrderSyncScheduler` 발행 키 실측 → AUCTION 미발행(GMARKET이 G마켓/옥션 포괄). AUCTION dot 추가 시 영구 회색 오해 dot → 무변경이 정답(실측 근거).
- **D-035 detailHtml XSS**: 운영 실데이터에 `<img>` 등 HTML 포함(D-021 맥락) → sandbox iframe(`sandbox=""`)으로 스크립트 차단 렌더, dangerouslySetInnerHTML 회피.
- **D-036 R2 환경이슈 구분**: 이미지 업로드는 R2 자격증명 필요(D-020) → 미설정 시 조용한 실패 대신 명확한 에러 토스트로 코드결함/환경이슈 구분.
