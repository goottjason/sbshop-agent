# 마켓 배지 클릭 등록 — 라이브 검증 체크리스트

대상 배포: `abed4e4` (2026-08-14). 상품 관리 화면에서 순서대로 진행한다.

**먼저 읽을 것 — 정상인데 버그로 오인하기 쉬운 3가지**

1. **등록 직후 쿠팡 배지는 링크가 되지 않는다.** publish는 `sellerProductId`를 주는데 링크는 `productId`가 필요하다. 백필 서비스가 나중에 채운다. 등록 직후의 올바른 모습은 "채색 테두리 + 반투명"(링크 없는 등록 상태)이다.
2. **11번가는 등록해도 링크가 끝내 생기지 않는다.** 백필 대상 마켓에 11번가가 없다.
3. **카페24 배지는 링크가 없는 게 정상이다.** 카페24는 상품페이지 URL을 만들 방법이 없어 채색 배지로만 표시되고 클릭해도 열리지 않는다.

## 실패를 발견했을 때

- **기대와 다른 동작** → `docs/normalize/defect-ledger.md`에 등재하고, 재현 상품 sbCode와 화면 캡처를 남긴다.
- **판단이 애매한 것**(정상인지 결함인지) → 위 "먼저 읽을 것" 3가지에 해당하는지 먼저 확인한다.
- **D1(11번가 거부)가 자주 걸린다** → 이건 알려진 한계다. 11번가용 카테고리 해석기가 코드베이스에 없어서 현재는 항상 거부된다. 등록을 실제로 열려면 11번가 카테고리 매핑 작업이 별도로 필요하다.
- **D2(카페24 거부)가 자주 걸린다** → 의도된 동작이지만 빈도가 과하면 알려달라. 자동매칭 기준을 완화하거나 초안 검수 경로로 유도하는 선택지가 있다.
