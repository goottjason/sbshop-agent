# 2026-07-20 11:45 결과서 — D-091 Cafe24 발주확인 PUT 포맷 수정(라이브 스펙)

## 개요
[[D-090]] 배포 후 사용자가 발주확인 재시도 → "Cafe24 API PUT 호출 실패". 예고했던 미검증 `acceptOrder` PUT 포맷 오류가 라이브에서 노출됨. 사용자가 Cafe24 정식 배송상태처리 API 스펙을 제공해 정확히 수정했다.

## 근본원인 (D-091)
`Cafe24OrderApiClient.acceptOrder`가 3가지 오류:
| 항목 | 현재(오류) | 스펙(정정) |
|------|-----------|-----------|
| 엔드포인트 | `PUT /admin/orders/{id}` | `PUT /admin/orders` (경로에 id 없음) |
| 바디 키 | `request`(객체) | `requests`(배열) |
| 상태 필드·값 | `status: "N20"` | `process_status: "prepare"` |

핵심: Cafe24 **읽기**(order_status: N00/N10/N20…)와 **쓰기**(process_status: prepare/prepareproduct/hold/unhold)가 **별개 어휘**였다. 기존 코드는 읽기 코드(N20)를 쓰기에 그대로 넣어 실패. `prepare=배송준비중(=발주확인)`이라 D-088 읽기매핑(N20→PREPARING)과 종단 일관.
