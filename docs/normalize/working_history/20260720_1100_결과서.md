# 2026-07-20 11:00 결과서 — D-089 배치 진행바 클라이언트 격리 → SSE 실시간 공유

## 개요
사용자 신고: "내가 배치업데이트한 것은 동업자 컴퓨터에서 안 보이고, 동업자가 한 것은 내게 안 보인다." 배치 진행바가 **개시 브라우저의 localStorage**로만 구동돼 클라이언트 간 격리됐다. A안(SSE 실시간 공유)으로 TDD 수정했다. 관련 [[deploy-and-jvm-topology]].

## 근본원인 (D-089)
`BatchUpdatePage.tsx`의 진행 카드가 `localStorage['sbshop.activeBatchId']`에 저장된 batchId 하나로만 폴링(`startTracking`). batchId는 배치를 **개시한 브라우저에만** 반환·저장되므로 타 클라이언트/타 기기는 그 batchId를 알 수 없어 진행바가 뜨지 않는다. 배치 상태는 공유 DB(`ProcessStatus`)에 있고 전역 SSE 브로드캐스트(`SseNotificationController.emitters`)도 존재하나, ① BatchUpdatePage가 SSE 미구독 ② SSE가 `BATCH_COMPLETED/FAILED`(완료)만 방송하고 **배치 시작(batchId 전파) 이벤트가 없어** 타 클라이언트가 진행 중 배치를 발견할 경로가 전무했다.

## 동작/한계
- 진행바는 **단일 batchId 슬롯** — 최근 시작된 배치가 모든 클라이언트에 표시(latest-wins). 서로 다른 jobType 동시 배치는 드물며, 완료건 상세는 `ProcessStatusPage`에서 공유 가시. 다중 동시 배치 UI가 필요해지면 후속 개선 후보.
- SSE는 api 단일 JVM 전역 emitters라 배포로 재연결되며, EventSource 자동 재접속으로 복구.
