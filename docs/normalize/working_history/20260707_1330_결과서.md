1. **P0 확정**: `defer-datasource-initialization: true` + Flyway 조합이 실 PostgreSQL에서 flyway↔entityManagerFactory 순환으로 **컨텍스트 기동 자체를 차단** — testcontainers Red로 실증 후 defer 제거로 Green. 운영 설정이 정확히 이 조합이었으므로, D-001/D-009(빈 충돌) 뒤에 숨어 있던 두 번째 기동 차단막이었음.
2. **세 번째 기동 차단 요인 발견·해소**: `flyway-database-postgresql` 모듈 부재 — Flyway 10.x가 실 Postgres에서 "Unsupported Database"로 실패. runtimeOnly 추가(리더 사후 승인). **worker도 동일 의존이므로 worker Flyway도 막혀 있었을 개연** — 배포 후 확인 권고.
3. **V5 멱등 3경로 실증**: market_specific_data 부재/TEXT 선존재/varchar(50000) 선존재 → 모두 최종 TEXT 수렴 (엔티티 정합). after-migrate의 나머지 7개 효과는 V4가 커버(대조표는 `_workspace/fixes/D-005_fix.md`, 휘발 — 요지: jsonb 변환·detail_html·delivery_fee/stock_status/restock_date·sb_currency/sb_supplier/sb_process_status 모두 V4 동일).
