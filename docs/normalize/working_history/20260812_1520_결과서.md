# 2026-08-12 15:20 결과서 — G마켓 유령 리스팅과 조용한 미매핑 (D-162)

사용자 신고: *"5ffd2a8e27776 상품코드가 이렇게 되어있는데 201203IHB008 이 상품이거든. 주문
4478251768. 어떻게 해결해야할까?"*

## 진단이 바꾼 것

**신고는 "코드가 이상하다"였고, 실제는 매출 누수였다.**

`5ffd2a8e27776`은 카페24 상품코드가 아니다. **G마켓 리스팅의 판매자 관리코드**다. 카페24 주문
API 원문이 그것을 `market_custom_variant_code`로 주고 있었고, 우리는 그 필드를 읽지도 않았다.

```
product_no                 = -99999          ← 카페24 몰 상품 미연동
product_code               = 2005125893      ← G마켓 상품번호
custom_product_code        = null
market_custom_variant_code = 5ffd2a8e27776   ← 사용자가 본 그 값
```

ESM+ 3,353개 전수 스캔(`POST /api/ea/goods/search`, 7페이지)에서 난수 코드 **13건**을 찾았다.
12건은 **정상 코드 리스팅이 이미 따로 있는 중복**이었다. 연동이 없어 우리 재가격 배치가 닿지
않았고, 그래서 **등록 시점 가격에 얼어붙어** 대부분 정상 리스팅보다 쌌다.

| 상품 | 유령가 | 정상가 | 차액 |
|---|---:|---:|---:|
| 기버터(이번 주문) | 64,400 | 85,900 | **-21,500** |
| 솔라레이 마그네슘 | 39,400 | 52,100 | -12,700 |
| 초크제로 | 33,100 | 44,500 | -11,400 |
| 닥터베스트 징코 | 47,500 | 57,700 | -10,200 |

같은 상품이 검색에 둘 뜨면 구매자는 싼 쪽을 산다. 이번 건은 기버터 2개 128,800원 — 정상
리스팅이었으면 171,800원. **한 건에 43,000원.** 그리고 13건 중 **11건이 재고 99999(무한)** 이라
실재고 0이어도 계속 주문을 받고 있었다.

전체 명세: `docs/normalize/esm-ghost-listings-20260812.md`

## 코드가 고친 것 — 침묵

매핑 실패는 값 하나가 비는 것으로 끝나지 않는다. **재고·정산·소싱이 전부 상품에 매달려 있어서
그 주문은 파이프라인 전체에서 빠진다.** 그런데 신호가 주문 화면의 `-` 하나뿐이었다. 08-11 주문을
사람이 하루 뒤 눈으로 발견할 때까지 아무도 몰랐다.

| 층 | 내용 |
|---|---|
| 표면화 | `MarketLineItemSyncDispatcher.warnUnmapped` — 상품 못 붙인 라인아이템을 WARN |
| 단서 | 경고에 마켓 식별자·상품명·라인아이템 id를 싣는다 |
| 수집 | `Cafe24LineItemMapper`가 `market_custom_variant_code` 수집 |
| 화면 | `OrderGrid` 상품코드 `-` → 빨간 **미매핑** 배지 |

경고는 **공통 골격**에 넣었다 — 네 마켓(쿠팡·스토어·11번가·Cafe24)이 모두 이 골격을 지난다.

**침묵을 지키는 경계**: 정책이 상품을 못 줘도 **채택한 기존 행이 이미 알고 있으면 경고하지
않는다.** 값이 멀쩡한데 경고를 내면 사람이 경고를 무시하는 법을 배운다.

**폴백을 넓히지 않았다**: `custom_product_code`/`market_custom_variant_code`로 `sb_code`를 직접
조회하는 폴백도 검토했으나 **이 사건은 못 푼다** — 유령의 코드는 난수라 우리 DB 어디에도 없다.
진짜 해결은 마켓 쪽 정리였고, 코드가 할 일은 다음번엔 사람이 즉시 알게 하는 것이다.
