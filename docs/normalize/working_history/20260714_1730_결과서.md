## 핵심 결정과 이유
- **TDD로 오탐 확정**: "잘못된 enum → 500" 발견사항 중 실제 500은 `GET /market-credentials/{marketType}`(enum을 경로변수 **타입**으로 직접 바인딩)뿐. F-PROD-2·PSRC-12·MREG-3·BATCH-B1은 `String`+`valueOf` 구조라 이미 400(기존 IllegalArgumentException 핸들러)이었음 → 회귀방지 테스트로 고정하고 체크리스트에 `[~] 오탐`으로 표기. **문서 발견사항을 코드로 검증하는 절차의 실효성 확인.**
- **SP-6 성공 경로 한정**: 실패 경로(F-ORD-5·15) marketType은 조회 자체가 실패했을 수 있어 무리하지 않고 보류. 일괄(다마켓)·customs·batch의 null은 의도된 것으로 유지.
- **부작용 없는 read-only 조회 분리**: `OrderService.marketTypeOfLineItem/marketTypeOfOrder` 추가 — 마켓 전송/비즈니스 로직 무변경(로깅 전용). core 시그니처는 추가만이라 worker 호출부 영향 없음.
