# 2026-10-07 전체 기능 점검

## 범위와 판정 기준

사용자 요청에 따라 백엔드·프론트엔드 전 기능을 목록화하고 기존 자동화 테스트, 새 결함 재현 테스트, 실제 브라우저, 운영 읽기 API를 대조했다. 명백한 오류의 수정·시험 및 시험 통과 후 배포를 승인받았다. 기존 운영 상품·주문을 생성/삭제/취소하거나 판매가·재고·송장을 시험 목적으로 변경하지 않았다.

이 결과의 **자동화 회귀 통과**, **운영 조회 성공**, **실마켓 쓰기 검증**은 서로 다른 보증이다. 마켓 등록·수정·이미지 업로드·주문 조치의 쓰기 경로는 격리된 테스트와 가짜 외부 응답으로 검증했으며, 운영 전체 상품의 최종 마켓 일치까지 확인한 결과가 아니다.

## 다음 단계 참조

1. 이 저장소의 추천 자동화는 정기 **후보 발굴**까지이며 선택·검수·게시에는 사용자 동작이 필요하다. 이번 점검을 무검수 자동 게시 기능 도입으로 해석하지 않는다.
2. 운영 전 상품의 외부 마켓 쓰기/심사 완료/최종 공개값 일치, 실 주문 취소·발송, 실제 R2 신규 업로드는 실행하지 않았다. 외부 마켓 권한·정책 거절과 MarketPlus 관측 지연은 코드 회귀 통과만으로 해결되지 않는다.
3. SB코드 동시성 보호는 현행 단일 API JVM을 전제로 한다. 인스턴스를 늘리기 전 분산 번호 예약·스케줄러 리더 선출이 필요하다. 동시 등록 요청은 이미지 I/O 종료까지 직렬 대기한다.
4. DB의 scheduleCron은 기존 화면에 표시용으로 안내된 값이며 실제 실행 시각은 서버 cron 설정이다. 분산 실행 및 수동/정기 발굴의 완전한 단일 실행 보장은 별도 운영 설계 범위다.
5. 기존 문서의 미지원 기능·외부 응답 제약은 이번에 임의로 자동 활성화하지 않았다. 실제 전체 상품 반영 검증 시에는 마켓별 현재 계정·상품 상태·지원 필드별 확인이 필요하다.

6. 기존 D-326의 Cafe24 미연결 주문 자동 매핑 폴백은 이번 변경에서 구현하지 않았다. 현재 수동 연결을 이용하며, 자동화하려면 마켓별 식별자의 유일성·상충 검증이 필요하다. 프로세스 종료로 PUBLISHING에 남거나 외부 등록 결과가 불확실한 초안도 임의 재게시하지 말고 실제 마켓 연결을 확인해야 한다.
