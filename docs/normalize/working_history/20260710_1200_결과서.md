## 핵심: D-045 ESM+ 는 "코드 통과 / 라이브 미확정" (정직)

원격에서도 ESM+ 동기화가 안 되는 상태였다. 진단 결과 **가장 유력한 코드결함 = `loadAndValidateCredential`이 secretKey(비밀번호)를 검증하지 않아 빈 비번이 조용히 로그인 실패**("성공 0건" 위장의 ESM+ 판 — 강한 Red로 실증). 수정:
- secretKey `hasText` 검증 fast-fail.
- 로그인 성공 판별(WebDriverWait로 `signin.esmplus.com` 이탈 확인) + `#innerIFrame` WebDriverWait + 미발견 시 HTML 스냅샷 로깅·구분 예외.

**단, `#innerIFrame` 미발견의 진짜 근본원인**(자격증명 유효성/추가인증/DOM 변경/로그인판별 휴리스틱 정확도)은 **실 ESM+ 계정 라이브 로그인 없이는 확정 불가**. 이 수정은 "무모하게 실패→명확한 진단신호로 실패"로 바꾼 것 — **가짜 그린 위험**을 명시하며, 재배포 후 실계정 라이브 검증이 필수다.
