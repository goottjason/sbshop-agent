# 2026-08-14 상품 그리드 마켓 배지 클릭 등록 — 결과서

## 무엇을 했나

상품 관리 그리드의 마켓 컬럼을 **6슬롯 고정 배지**(쿠팡·N스토어·카페24·G마켓·옥션·11번가)로 바꾸고,
미등록 마켓을 점선으로 드러내 그 자리에서 클릭 등록할 수 있게 했다.

- 배지 클릭 → 마진율·쿠폰율·최소마진 입력 다이얼로그 → **마켓별 실수수료 반영가**로 등록
- G마켓·옥션은 상품등록 API가 없어 **Cafe24 마켓플러스 딥링크 핸드오프**(상품코드·URL·안내 반환)
- 등록 미완료(PENDING) 상태를 주황 배지로 분리

## 마켓플러스 실측 (스파이크)

`docs/normalize/working_history/20260813_marketplus_스파이크.md` 참조. 핵심:

- 미판매 목록은 **Cafe24 `product_code` 완전일치**로만 검색된다 — sbCode로는 0건이고 화면에 노출조차 안 됨
- 전송 팝업에서 **상품마다 마켓 카테고리 4단계를 수동 선택**해야 함 (배송/반품 템플릿은 계정별 자동)
- 전송 팝업에 reCAPTCHA 로드됨
- 전송은 비동기 큐 — 마켓 상품번호가 즉시 나오지 않음
- G마켓 계정은 상품 수량 초과로 전송 차단 상태 (판매자센터 수동 정리 필요)

→ 무인 자동 전송이 성립하지 않아 **딥링크 핸드오프**로 설계 변경(사용자 결정). Playwright 전송 자동화는 폐기.

## 알려진 한계 (결함 아님)

- **11번가는 등록해도 배지 링크가 생기지 않는다** — `MarketLinkIdentifierBackfillService`의 백필 SPEC에 11번가가 없다
- **쿠팡은 등록 직후 링크가 없다** — publish가 `sellerProductId`를 주는데 링크는 `productId`가 필요. 백필이 나중에 채운다

- G마켓 전송 한도 초과는 판매자센터에서 수동 정리 필요
