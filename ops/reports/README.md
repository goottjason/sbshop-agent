# 외부 잔여 상품 조회

`soft-deleted-external-listings.sql`은 SB에서 소프트 삭제되었지만 외부 삭제가 확인되지 않은 G마켓·옥션·11번가의 상품번호 및 상품코드가 없는 스마트스토어의 미확인 기록를 읽기 전용으로 조회한다.

- 신규 삭제: sb_product.deletion_followup에 삭제 당시 마켓·상품번호·사유·시각을 보존한다. 상품의 소프트 삭제와 동일 트랜잭션으로 저장한다.
- 과거 삭제: 등록 이력에서 카페24 자식 마켓 번호와 삭제 확인되지 않은 11번가 번호를 조회한다.
- 원래 상품·주문·마켓 등록 이력은 삭제하지 않는다.
- 이 목록은 수동 삭제를 위한 후보 목록이다. 기록 후 사용자가 마켓에서 삭제했을 수 있으므로 현재 존재가 실시간 검증됐다는 의미는 아니다.
- 11번가 브라우저 삭제 구현은 보류되었으며, 지원되지 않는 DELETE 호출은 상품 삭제 흐름에서 사용하지 않는다.
